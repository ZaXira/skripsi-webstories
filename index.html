03 · Metodologi

Pipeline End-to-End

Tiga tujuan penelitian dirangkai menjadi satu pipeline terpadu: deteksi poligon lahan → ekstraksi fitur perubahan 6 layer → klasifikasi kerusakan, lalu dikemas sebagai aplikasi web live.

T1
Segmentasi Instance Lahan Pertanian (Tujuan 1)
Citra PRE-disaster → Mask R-CNN (Detectron2, R50-FPN) → Poligon lahan pertanian
Dibandingkan dengan: YOLOv8-seg
T2
Ekstraksi Fitur & Klasifikasi Kerusakan (Tujuan 2)
Pasangan PRE & POST → 6 layer fitur kontinu per poligon → Random Forest / LightGBM → 3 kelas kerusakan
T3
Integrasi End-to-End (Tujuan 3)
Mask R-CNN → fitur per poligon terdeteksi → Random Forest → Penilaian end-to-end
Evaluasi: formula skor gabungan xView2 (Gupta dkk., 2019)
WEB
Artefak Web — Aplikasi Inferensi Live
Gradio + Hugging Face Spaces ZeroGPU — pipeline Tujuan 3 secara interaktif tanpa pelatihan ulang

07 · Artefak Web

Aplikasi Web Inferensi Live

Pipeline Tujuan 3 dikemas sebagai aplikasi Gradio dan di-deploy ke Hugging Face Spaces ZeroGPU — inferensi end-to-end interaktif, tanpa pelatihan ulang, ~22 detik per pasang citra.

Temuan 1
Portabilitas Ruang Piksel Terbukti
6 layer fitur murni operasi numpy/cv2 pada nilai piksel. Divalidasi 115 poligon — ruang piksel vs geografis identik bit-per-bit (max|beda| = 0,0000). CRS hanya label kontainer GeoDataFrame.
Temuan 2
Dua Preprocessing Berbeda, Satu Pipeline
Deteksi: min-max gabungan 3 band (replikasi training Tujuan 1). Fitur: percentile 2–98 per band. Keduanya sengaja berbeda — bukan bug, wajib dipertahankan.
Temuan 3
Cara Konversi 8-bit Tentukan Recall
Min-max gabungan: 96,8% lahan terdeteksi. Percentile per band: 40,3%. Model dilatih pada min-max — stretch per band merusak keseimbangan warna antar band yang dipelajari model.
Temuan 4
TF32 Menggeser Hasil Lintas Generasi GPU
GPU Ampere+ (ZeroGPU) pakai TF32 secara default; T4 tidak. Solusi: matikan TF32 eksplisit → hasil kembali identik. Implikasi: klaim reproduksibilitas DL perlu menyebut presisi aritmetik.

08 · Kesimpulan

Temuan Utama Penelitian

Ketiga tujuan penelitian terjawab penuh dengan keterbatasan struktural yang terdokumentasi. Pipeline end-to-end berhasil divalidasi 100% identik dan di-deploy sebagai aplikasi web live.

Tujuan 1
Segmentasi Instance
Mask R-CNN lebih unggul dari YOLOv8-seg — precision instance lebih tinggi substansial, recall serupa. ~34% lahan aktual tidak terdeteksi (keterbatasan struktural, membaik dari 42% via DETECTIONS_PER_IMAGE=500 di Tujuan 3).
